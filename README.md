# Personal Portfolio

A personal portfolio website showcasing my web development projects, skills, and contact information.

About

This portfolio is designed to present my work as a student developer and demonstrate my experience with front-end web development.

The site focuses on keeping things simple, clean, and easy to navigate while giving potential clients or employers a place to view my projects.

Features

- Responsive navigation
- Dedicated Projects page
- Dedicated Contact page
- Project links to live websites
- Responsive layout for smaller screens
- Custom styling with CSS
- Google Fonts integration
